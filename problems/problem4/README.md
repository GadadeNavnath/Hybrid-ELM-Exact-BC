#### Problem 4: Three-Dimensional Nonlinear Partial Differential Equation

We consider the three-dimensional nonlinear partial differential equation:

$$
u_{xx}+u_{yy}+u_{zz}-u^2 = (2+y^2)e^x-z^2\sin(y)-\Big(e^x y^2+(z^2+2)\sin(y)\Big)^2,
$$

defined on the physical domain

$$
0.5 \le r \le 1,\qquad
0 \le \theta \le \frac{\pi}{2},\qquad
0 \le \phi \le \frac{\pi}{2},
$$

where $$(r,\theta,\phi)$$ denote spherical coordinates. For numerical implementation, the problem is reformulated in Cartesian coordinates $$(x,y,z)$$.

The exact solution is given by:

$$
u(x,y,z) = e^x y^2 + (z^2+2)\sin(y).
$$

---
#### Boundary Conditions (BCs)

All BCs are derived from the exact solution.

• Dirichlet BCs: Dirichlet conditions are prescribed on the entire boundary.

• Neumann BCs: Neumann conditions are prescribed on the entire boundary.

• Mixed BCs: Neumann BCs are prescribed on the inner and outer spherical surfaces (r = 0.5 and r = 1), while Dirichlet BCs are imposed on the coordinate planes x = 0, y = 0, and z = 0.

---

#### Folder Structure

Each case folder contains the following files and subfolders:

1. `Figures/`

   - Contains the figures generated by the numerical simulations.

2. `data/`

   - Contains the training data and numerical results generated during the computations, including interior points, boundary points, boundary normals (if required), and other required matrices or solution data.

3. `domain.py`

   - Generates the physical domain, interior points, boundary points, and other required data, which are stored in the `data` folder.

4. Numerical implementation scripts

   - The implementation files depend on the boundary-condition case. For the Dirichlet and Mixed cases, `main.py` implements the proposed hybrid ELM framework.
   - For the Neumann case, `main_1.py` implements the proposed hybrid ELM framework, while `main_2.py` implements the Lagaris framework using PyTorch as a baseline for comparison.

5. `Comparison plots.py`

   - The Neumann case additionally contains a comparison plotting script that loads the numerical results generated by `main_1.py` and `main_2.py` from the `data` folder and generates the corresponding comparison figures.
---

#### Usage

For each boundary-condition case:

1. Run `domain.py` to generate the required training data and store it in the `data` folder.

2. Run the corresponding numerical implementation to solve the PDE and generate the required numerical results. For the Dirichlet and Mixed cases, run `main.py`.

3. For the Neumann case, run `main_1.py` for the proposed hybrid ELM framework and `main_2.py` for the Lagaris framework.

4. For the Neumann case, run `Comparison plots.py` to load the results generated by `main_1.py` and `main_2.py` from the `data` folder and generate the comparison figures.

5. The generated plots can be found in the `Figures` folder.
