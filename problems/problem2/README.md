#### Problem 2: Nonlinear Elliptic Partial Differential Equation

We consider the nonlinear elliptic partial differential equation:

$$
u_{xx} + u_{yy} + e^u = 1 + x^2 + y^2 + \frac{4}{(1+x^2+y^2)^2},\qquad (x,y)\in\Omega,$$

where $$\Omega$$ is the cardioid-shaped domain defined by

$$ r = 1+\cos\theta. $$

The exact solution is given by:

$$u(x,y)=\log(1+x^2+y^2).$$

---
#### Boundary Conditions (BCs)

All BCs are derived from the exact solution.

• Dirichlet BCs: Dirichlet conditions are prescribed on the entire boundary.

• Neumann BCs: Neumann conditions are prescribed on the entire boundary.

• Mixed BCs: Dirichlet conditions are imposed on the boundary portion where y ≥ 0, while Neumann conditions are imposed where y < 0.

---

#### Folder Structure

Each case folder contains the following files and subfolders:

1. `Figures/`

   - Contains the figures generated by the numerical simulations.

2. `data/`

   - Contains the training data and numerical results generated during the computations, including interior points, boundary points, boundary normals (if required), and other required matrices or solution data.

3. `domain.py`

   - Generates the physical domain, interior points, boundary points, and other required data, which are stored in the `data` folder.

4. Numerical implementation scripts

   - The implementation files depend on the boundary-condition case. For the Neumann and Mixed cases, `main.py` implements the proposed hybrid ELM framework.
   - For the Dirichlet case, `main_1.py` implements the proposed hybrid ELM framework, while `main_2.py` implements the Lagaris framework using PyTorch as a baseline for comparison.
   
5. Comparison plotting script

   - The Dirichlet case additionally contains a comparison plotting script that loads the numerical results generated by `main_1.py` and `main_2.py` from the `data` folder and generates the corresponding comparison figures.
     
#### Usage

For each boundary-condition case:

1. Run `domain.py` to generate the required training data and store it in the `data` folder.

2. Run the corresponding numerical implementation to solve the PDE and generate the required numerical results. For the Neumann and Mixed cases, run `main.py`.

3. For the Dirichlet case, run `main_1.py` for the proposed hybrid ELM framework and `main_2.py` for the Lagaris framework.

4. For the Dirichlet case, run the comparison plotting script to load the results generated by `main_1.py` and `main_2.py` from the `data` folder and generate the comparison figures.

5. The generated plots can be found in the `Figures` folder.
