#### Problem 3: Nonlinear Elliptic Partial Differential Equation

We consider the nonlinear elliptic partial differential equation:

$$
-\left(u_{xx}+u_{yy}\right)+u^3 = 2\pi^2\sin(\pi x)\sin(\pi y) + \sin^3(\pi x)\sin^3(\pi y),\qquad (x,y)\in\Omega,$$

where $$\Omega$$ is a highly irregular physical domain corresponding to the geographical boundary of Sweden.

The exact solution is given by:

$$
u(x,y) = \sin(\pi x)\sin(\pi y).$$
