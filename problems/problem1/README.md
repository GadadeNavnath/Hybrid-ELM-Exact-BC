#### Problem 1: Linear Elliptic Partial Differential Equation

We consider the linear partial differential equation:

$$
u_{xx} + u_{yy} = e^{-x}\left(x-2 + y^3 + 6y\right), \qquad (x,y)\in[0,10]\times[0,10].
$$

The exact solution is given by:

$$
u(x,y) = e^{-x}\left(x+y^3\right).
$$

---
#### Boundary Conditions (BCs)

All BCs are derived from the exact solution.

• Dirichlet BCs: Dirichlet conditions are prescribed on the entire boundary.

• Mixed BCs: Neumann BCs are imposed on the left and right boundaries (x = 0, 10), while Dirichlet BCs are prescribed on the bottom and top boundaries (y = 0, 10).

---

#### Folder Structure

Each case folder contains the following files and subfolders:

1. `Figures/`
   - Contains the figures generated by the numerical simulations.

2. `data/`
   - Contains the training data, including interior points, boundary points, boundary normals (if required), and the matrix `K` (where applicable).

3. `domain.py`
   - Generates the physical domain, interior points, boundary points, and other required data, which are then stored in the `data` folder.

4. `main.py`
   - Solves the corresponding problem, computes the approximate solution, evaluates the $$L_{\infty}$$ and RMS errors, and generates the associated plots.

---

Usage

1. Run `domain.py` to generate the training data and store it in the `data` folder.
2. Run `main.py` to solve the PDE, compute the error metrics, and generate the figures.
3. The generated plots can be found in the `Figures` folder.
